# Mobtwig 로고 수정본 v2

원래 펼친 책의 양옆 돌기와 수직 가지를 유지했습니다. 외곽선과 중앙 제본선을 가늘게 조정하고, 잎맥과 책장 하단의 겹침선을 추가했습니다. 수정 전후는 `preview.png`에서 비교할 수 있습니다.

## 파일 목록

| 파일 | 크기 | 용도 |
| --- | --- | --- |
| `master.png` | 1254 × 1254 | 수정 후 투명 원본입니다. |
| `logo-1024.png` | 1024 × 1024 | 범용 투명 로고입니다. |
| `app-icon-1024.png`, `app-icon-512.png` | 1024 / 512 정사각형 | 크림색 배경을 포함한 앱 아이콘입니다. |
| `header.png`, `header@2x.png`, `header@3x.png` | 32 / 64 / 96 정사각형 | 메인 화면 좌측 상단용입니다. 표시 크기는 32입니다. |
| `small.png`, `small@2x.png`, `small@3x.png` | 24 / 48 / 72 정사각형 | 작은 UI용입니다. 표시 크기는 24입니다. |
| `splash.png`, `splash@2x.png`, `splash@3x.png` | 256 / 512 / 768 정사각형 | 시작 화면 중앙에 배치하는 투명 로고입니다. |
| `preview.png` | 1200 × 850 | 수정 전후 비교와 배치 시안입니다. 실제 앱 캡처는 아닙니다. |

## 제작 및 사용

내장 이미지 생성 도구에 원형 유지, 수직 가지, 양옆 돌기 보존, 얇은 윤곽과 중앙선, 잎맥 및 책장 하단 곡선 추가를 지시했습니다. 디자인 수정과 투명 배경 처리를 마친 후 동일한 `master.png`에서 모든 사용 이미지를 내보냈습니다.

화면 내부용은 투명 배경입니다. 밝은 화면에 사용하며, 어두운 화면에서는 밝은 배경 영역 위에 배치합니다. 앱 아이콘 배경은 `#FFF5DF`입니다. 가로세로 비율을 유지하며, 2배·3배 파일도 기본 파일과 같은 표시 크기로 사용합니다. `Mobtwig` 글자는 로고 파일에 포함하지 않았으므로 별도 텍스트로 배치합니다.

실제 PNG 크기와 배경 투명도를 확인했습니다. 24 크기에서는 잎맥과 책장선이 약해질 수 있으며, `preview.png`에 실제 픽셀 크기로 표시했습니다. 앱 코드 및 플랫폼별 아이콘 설정 연결과 실제 기기 검증은 수행하지 않았습니다.
