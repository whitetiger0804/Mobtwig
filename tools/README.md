# 로컬 시드

로컬 MySQL 컨테이너를 실행하고 서버를 한 번 기동해 V1~V13을 적용한 뒤 저장소 루트에서 실행합니다.

```powershell
node tools/db-seed.mjs seed
```

16개 작품·536개 회차·상품 491개를 준비합니다. 기본 가격은 도서 전체 5,000원, 매거진 한 호 3,000원, 웹소설 첫 화 무료·이후 회차당 100원입니다. 구매 기록은 생성하지 않습니다.

`seed-content/`에는 원고와 잡지 PNG 원본을 보관합니다. 510개 TXT·532개 PNG와 `manifest.json`을 함께 공유합니다. 실행 시 UTF-8·정규화 UTF-16 길이·텍스트 SHA-256·파일 경로를 검사한 뒤 비공개 본문 루트로 복사합니다. `CONTENT_ROOT`는 프로세스 환경변수, `server/.env`, 기본 `server/content` 순서로 결정합니다. `.env`의 상대 경로는 `server/` 기준이며 경로는 `/`로 작성합니다. Docker Compose 프로젝트는 `compose.yaml`의 기본 이름과 표준 `COMPOSE_PROJECT_NAME` 환경변수를 따릅니다.

같은 명령을 다시 실행해도 기존 계정·리뷰·구매·독서 활동·상품 가격을 초기화하지 않습니다. 기존 시드에도 빠진 상품과 본문 연결을 추가합니다. TXT를 수정하면 `manifest.json`의 `characterCount`와 `contentHash`도 새 본문에 맞춰 갱신합니다. 본문 파일 또는 현재 버전에 고정된 해시가 바뀌면 해당 회차의 본문 버전을 갱신하고 새 버전에 검증한 해시를 등록합니다. 기존 버전의 고정 해시는 덮어쓰지 않습니다. 초기 본문 연결 때만 북이 계정의 좌표·버전 연결과 하이라이트 해시를 실제 본문에 맞춥니다.

변경 대상 파일의 이전 bytes를 실행 중 메모리에 보관하고 임시 파일을 거쳐 교체합니다. 파일 교체나 SQL이 실패하면 이번 실행에서 교체한 본문만 복원합니다. 복원 전에 다른 작업이 해당 파일을 수정한 경우에는 그 값을 덮어쓰지 않고 오류 경로를 출력합니다. 시드 실행 중에는 같은 본문 파일을 별도로 편집하지 않습니다.

```powershell
node tools/db-seed.mjs unseed
```

예약한 시드 행·상품만 제거하며 원본·복사된 본문 파일은 보존합니다. 후속 구매나 별도 첨부·관계가 있으면 제거하지 않습니다. 회차 삭제로 해당 회차의 버전 레지스트리만 함께 제거되며 다른 회원의 독서·책갈피·하이라이트 참조가 있으면 작업을 롤백합니다. 활동까지 지우는 반복 테스트는 별도의 폐기 가능한 DB에 V1~V13을 적용한 뒤 진행합니다. 본문 원본은 Git으로 공유하지만 실행 폴더의 비공개 본문과 실제 DB 파일은 기존 제외 설정을 유지합니다.
