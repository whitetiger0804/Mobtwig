4장 · 화면을 연결합니다

목록에서 책을 누르면 상세 화면으로 이동하도록 만들 차례입니다. 먼저 종이에 목록, 상세, 돌아오기라는 세 동작을 그립니다. 상세 화면에는 어떤 책을 선택했는지 알려 줄 식별자가 필요합니다. 제목은 같은 책이 있을 수 있고 나중에 바뀔 수도 있으므로 예시 자료에 정해 둔 책 ID를 전달하기로 합니다. 화면 사이에 필요한 정보를 정하는 일이 이동 효과를 고르는 일보다 앞섭니다.

화면 이동에는 프로젝트가 선택한 내비게이션 도구를 사용합니다. 구체적인 함수 이름은 도구에 따라 다르지만 현재 화면, 이동할 목적지, 전달할 값이라는 관계는 공통적으로 살필 수 있습니다. 상세 화면은 전달받은 ID로 해당 책의 정보를 찾습니다. 목록의 모든 표시 내용을 길게 복사해 넘기면 두 화면이 서로 다른 정보를 보여 줄 수 있으므로 자료를 읽는 기준도 함께 정합니다.

돌아가기 역시 화면의 일부입니다. 사용자가 상세 화면에서 돌아왔을 때 검색어와 목록 위치를 유지할지 생각합니다. 무조건 첫 화면부터 다시 시작하면 조금 전 찾은 책을 또 찾아야 합니다. 반대로 모든 이전 화면을 계속 쌓으면 같은 상세 화면이 여러 번 생길 수도 있습니다. 같은 항목을 연속으로 누르거나 여러 상세 화면을 차례로 여는 행동을 해 보며 이동 흐름을 확인합니다.

이 단계의 완료 조건은 이동 버튼이 한 번 작동하는 것보다 구체적입니다. 검색한 목록에서 책을 고르고, 그 책의 제목을 확인하고, 돌아와 같은 검색 결과를 볼 수 있어야 합니다. 잘못된 화면이 보이면 선택한 ID와 실제 표시한 ID를 비교합니다. 경로를 짧게 적어 두면 다음 장에서 서버 자료를 연결한 뒤에도 같은 사용자 행동으로 결과를 비교할 수 있습니다.
