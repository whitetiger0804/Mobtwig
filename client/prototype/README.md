# 모북이 전체 앱 프로토타입

요구사항명세서 0.3과 UI설계서 1.0에서 시작해 아래 개정 사항을 반영한 브라우저용 프로토타입입니다. 이 `client/prototype` 폴더는 기존 백과사전 단독 시연을 전체 앱 프로토타입으로 교체한 버전입니다. Expo 앱은 별도 개발하며 이 HTML 시연은 React Native 앱에 연결된 구현이나 실제 서비스가 아닙니다.

## 실행

앱 크기 화면으로 시연하려면 **`app-preview.html`**을 여세요. 데스크톱에서는 휴대폰 프레임 안에서 동일한 프로토타입이 실행되며, 작은 화면·기본 화면·큰 화면을 선택할 수 있습니다. 실제 모바일에서는 프레임을 숨기고 화면 전체를 사용합니다. 기존 PC형 화면은 `index.html`에서 계속 확인할 수 있습니다. 앱 미리보기는 HTML 기반 모바일 화면 시연이며 React Native 빌드 결과는 아닙니다.

이 폴더 전체를 내려받아 `index.html`을 Chrome 또는 Edge에서 엽니다. 패키지 설치와 빌드가 필요 없으며 외부 폰트나 이미지 요청 없이 동작합니다. 콘텐츠 관리 시연은 같은 폴더의 `admin.html`을 엽니다.

원한다면 이 폴더에서 로컬 웹 서버를 실행해 모바일 화면 크기로도 확인할 수 있습니다. 로컬 주소를 다른 팀원의 기기에 전달하는 것만으로는 접속할 수 없으므로, 팀 공유에는 폴더 전체 또는 압축 파일을 전달하세요.

초기 화면은 `민서` 시연 계정으로 로그인되어 있습니다. 계정 설정에서 로그아웃한 뒤 아래 계정으로 로그인 동작을 확인할 수 있습니다.

- 계정 `reader@mobtwig.demo`
- 비밀번호 `demo1234`

이는 공개된 가상 시연 정보입니다. 실제 인증 API를 호출하지 않으며 실제 비밀번호나 개인정보를 입력하지 마세요. 신규 가입은 이번 실행 중의 인증 정보를 메모리에 보관하는 시뮬레이션입니다. 새로고침 후에는 기존 로그인 상태를 유지할 수 있지만, 신규 계정으로 다시 로그인하는 서버 기능은 제공하지 않습니다. 기본 시연 계정은 계속 사용할 수 있습니다.

## 추천 시연 순서

1. 홈에서 읽던 작품의 **이어 읽기**를 눌러 저장된 2화 2페이지로 이동합니다.
2. 본문의 밑줄 용어 **공명**을 눌러 설정 설명을 확인합니다.
3. 상단 **설정집**을 열고 분류·세부 분류·검색을 사용합니다. 아직 읽지 않은 인물의 이름은 검색되지 않습니다.
4. 회차 목록으로 돌아가 3화를 읽으면 해당 위치에서 공개되는 인물이 설정집에 나타납니다.
5. **읽기 설정**에서 글자 크기 5단계, 배경 4종, 책장 넘기기·스크롤, 애니메이션·효과음을 선택합니다. 다른 작품을 열어 같은 설정이 유지되는지 확인합니다.
6. 북마크를 추가하거나 본문 문장을 선택한 뒤 **선택한 문장 하이라이트**를 누릅니다. 마이페이지의 북마크·하이라이트에서 본문으로 돌아갑니다.
7. 작품 상세에서 찜·서재 담기·링크 복사와 리뷰 작성을 시연합니다. 본인 리뷰와 댓글은 수정·삭제할 수 있습니다.
8. `admin.html`에서 작품 정보와 첫 회차 본문을 초안으로 저장합니다. **앱북 게시**에서 검증 후 게시하면 같은 브라우저의 독자용 검색 목록에 추가됩니다.

## 저장과 시연 정책

- 시연 데이터는 `mobtwig-app-prototype-v1` 키로 현재 브라우저의 로컬 저장소에 보관합니다. 사용자가 달라지면 서재·설정·독서 위치·기록도 분리됩니다.
- 위치와 진행률은 하나의 저장 객체에 함께 기록합니다. 실제 DB 트랜잭션이나 서버 동시성 보장을 구현한 것은 아닙니다.
- 저장소를 사용할 수 없거나 저장 공간이 부족하면 안내하고 현재 실행 중의 데이터만 사용합니다.
- 설정집은 시연에서 **최대 도달 위치**를 개방 기준으로 사용합니다. 앞으로 이동한 회차는 열람한 것으로 취급합니다. 이는 미확정 정책 D-05를 위한 임시 선택이며 서비스 정책 확정이 아닙니다.
- 샘플 작품은 회차당 3페이지입니다. 텍스트 글자 크기가 바뀌어도 회차와 페이지 기준 위치를 유지합니다. 실제 리플로우 엔진의 정밀 위치 설계와 별개입니다.
- 샘플 요약은 직접 작성된 정적 문구입니다. 자동 요약 API를 사용하지 않습니다. 1화에는 이전 회차 요약이 없습니다.
- 첫 작품은 인물·개념·세계관을 포함한 설정집이 준비되어 있고 다른 작품은 빈 설정집을 보여줍니다. 관리 화면에서 다른 작품의 설정집 항목을 등록할 수 있습니다.
- 애니메이션과 효과음은 각각 켜고 끌 수 있습니다. 음성·영상 재생은 제공하지 않습니다. 효과음은 사용자 조작 때만 브라우저 오디오로 생성합니다.
- 리뷰를 삭제하면 연결된 시연 댓글도 함께 삭제합니다. 이 삭제 정책은 시연용이며 실제 서비스 정책은 별도 검토 대상입니다.
- 링크 복사는 같은 프로토타입 실행 환경의 작품 주소를 만듭니다. OS 공유 시트, 외부 앱 딥링크, 앱 미설치 웹 안내는 미정 범위라 구현하지 않습니다.
- 관리 화면은 권한 검증이 없는 독립된 **시연 화면**입니다. 실제 인증·인가, 파일 업로드·보안 검사, CDN 배포, 관리자 계정은 구현하지 않습니다. 텍스트 본문을 등록하고 그 결과를 독자 화면에서 확인합니다.
- 모든 작품·작가·표지·본문·계정·초기 리뷰는 가상 자료입니다. 표지는 SVG로 직접 구성했습니다.

## 검증

Chrome 독립 세션에서 주요 동작 34개를 자동 검증했습니다. 검색과 빈 결과, 이어보기, 첫 회차 요약 제외, 설정집 잠금·검색 차단·개방, 공통 읽기 설정, 북마크·실제 하이라이트 표시, 리뷰와 댓글, 인증, 재실행 저장, 초안 게시를 확인했습니다. 데스크톱과 모바일 390px·375px에서 주요 화면을 검사했고 JavaScript 오류와 가로 넘침이 없었습니다. Android·iOS 네이티브 앱 또는 실제 서버 연동 검증은 수행하지 않았습니다.


## 2026년 10월 24일 홈 구성 업데이트

- 홈 기본 선택은 웹소설이며 헤더에서 웹소설/일반도서를 전환합니다. 각 탭의 배너·이어 읽기·인기작품은 해당 유형에 맞게 표시합니다.
- 원형 기본 프로필에서 마이페이지로 이동합니다. 사용자 사진 업로드 기능은 아직 없습니다.
- 추천 배너는 터치 가로 스크롤과 이전/다음 버튼으로 이동합니다. 실제 광고·공지 운영 연동은 없습니다.
- 웹소설 장르 17개와 전체 필터, 일간/주간 전환을 제공합니다. 미등록 장르는 빈 상태를 표시합니다.
- 기존 6개 가상 작품은 시연용으로 유형을 명시했고 장르 탐색용 웹소설 4개를 추가했습니다. 일반도서는 에세이 2개입니다. 실제 기존 도서의 이관 기준을 확정한 것은 아닙니다.
- 순위는 일간/주간별 고정 시연 점수로 정렬하며 실제 조회 집계·랭킹 알고리즘을 구현한 것은 아닙니다.
- 지난 이야기는 웹소설의 등록된 요약만 표시합니다. 일반도서와 요약이 없는 회차는 숨깁니다. AI 생성·작가 승인 작업실은 이번 홈 업데이트에 포함되지 않았습니다.
- 새 홈 검증: 유형 전환, 장르·빈 결과, 일간/주간 순서 변경, 배너 이동, 상세 진입, 360/390/430px 및 데스크톱 가로 넘침, 일반도서 요약 비노출과 웹소설 요약 유지 확인. 기존 모바일 미리보기 13개 검증도 통과했습니다. 앞의 34개 검증은 초기 버전 기록입니다.

## 설정집 개방 범위 설정

설정집 상단의 ‘개방 범위 설정’에서 자동(최고 도달 위치) 또는 직접 회차 끝까지 개방을 선택합니다. 아직 읽지 않은 범위는 스포일러 확인 체크 후 적용할 수 있습니다. 작품별·회원별로 저장되며 설정집 목록·검색·상세와 본문 용어 연결에 동일하게 적용합니다. 더 좁은 범위로 다시 잠그거나 자동으로 복귀할 수 있고 독서 위치·진행률은 변경하지 않습니다. 서버가 없는 시연이므로 실제 콘텐츠 보호를 보장하지 않습니다.

## 작품별 리뷰 제한

계정·작품별 현재 리뷰 1개만 허용하며 기존 작성자는 수정으로 연결합니다. 직접 주소에서도 기존 리뷰를 수정하고 등록 처리에서도 중복 요청을 거부합니다. 삭제 후 재작성은 가능합니다. 실제 서버의 유일성 제약과 다중 기기 동시성은 별도 구현 대상입니다.

홈 좌상단의 웹소설 버튼은 웹소설/모북이를 약 3초씩 교차 표시합니다. 버튼의 기능과 접근성 이름은 웹소설로 유지하며 레이아웃 폭은 고정합니다. 동작 줄이기 설정에서는 웹소설을 고정 표시합니다.

Genre strips support mouse drag and wheel scrolling as well as native touch scrolling. Dragging does not select a genre; clicking still applies the filter.

## 탐색 탭 콘티 업데이트 (2026년 10월 24일)

- 하단 검색 표시명을 탐색으로 변경하고 기존 #search 주소를 유지했습니다.
- 헤더 검색 팝업/종 알림 미리보기/원형 프로필, 요일 가로 필터(전체·월~일·비정기·완결), 여러 줄 장르 다중 선택, 목록형 결과, 최신/별점/조회 정렬을 제공합니다.
- 다중 장르는 OR, 다른 필터끼리는 AND입니다. 장르 재선택은 해제이며 제외 검색은 구현하지 않았습니다.
- 작품명·작가·태그를 검색하고 상단 검색 팝업에서 제출한 검색어는 탐색 입력창과 결과에 반영합니다. 입력 중 필터는 즉시 동작하며 최근 검색어는 검색 실행 때만 저장합니다.
- 최근 검색어는 계정별 중복 제거·최신 10개입니다. X로 개별 삭제하고 마이페이지 > 검색 설정에서 저장을 끄면 기존 기록도 삭제합니다. 비로그인 기록은 메모리에서만 유지됩니다.
- 상세 검색은 작품 유형, 연재/완결 상태, 최소/최대 회차 수이며 0은 하한 0/상한 무제한입니다. 최소>최대는 거부합니다. 성인 인증을 구현하지 않은 상태에서 성인 필터를 제공하지 않습니다.
- 요일·연재 상태·태그·갱신일·조회수는 가상의 시연 데이터입니다. 최신순은 시연 갱신일 기준이며 실제 서비스의 집계·정책 확정이 아닙니다.
- 알림은 빈 미리보기와 전체 보기 준비 중 안내만 제공합니다. 전체 알림 탭, 실시간 수신 및 읽음 처리는 아직 없습니다.
- 탐색 검증: 장르 조합/해제·요일/완결·태그·정렬·상세 조건·최근 검색어/저장 중단·알림·화면 크기를 확인했습니다. 기존 홈·설정집·리뷰 및 모바일 미리보기 13개 검증도 통과했습니다.

## 공통 헤더와 유형 분리 업데이트

홈·탐색·내 서재·마이페이지의 헤더를 통합하여 검색·알림·프로필을 공통 제공합니다. 웹소설/일반도서 선택은 탭 간 유지하며 탐색·서재·찜 결과도 선택 유형으로 제한합니다. 일반도서는 연재 요일을 표시하지 않고 현재 일반도서의 분류를 사용합니다. 유형 변경 시 장르·요일·상태·회차 조건은 초기화합니다. 검색 팝업은 상단 카드로 열리며 입력칸과 검색 버튼 폭을 분리했습니다. 360/390/430px iframe에서 입력 폭·경계·작동을 확인했습니다.

## 홈 배너 터치와 가로 스크롤바 (2026년 10월 24일)

`home-banners.js`는 기존 홈 배너를 보완합니다. 손가락으로 좌우 스와이프하면 브라우저의 기본 가로 스크롤·스냅을 사용하며 세로 페이지 스크롤도 유지합니다. 드래그/스와이프는 작품 상세 탭으로 처리하지 않습니다. 짧은 탭·웹 화살표·키보드 좌우/Home/End는 사용할 수 있고 웹의 양끝 화살표는 비활성화합니다. 마우스 드래그도 지원합니다.

배너·장르·요일 가로 영역은 시각적 스크롤바를 숨깁니다. 스크롤 자체와 터치·휠·드래그·키보드 포커스 이동은 유지하며 세로 스크롤바를 일괄 숨기지 않습니다. 실제 터치 입력으로 배너 스냅/오탭 방지/탭 상세/세로 스크롤을 확인했고, 요일 영역의 터치·휠·마우스 드래그·마지막 항목 포커스 이동과 360/390/430px 가로 넘침도 검증했습니다.

Expo 앱은 별도 `../src`에 개발되고 있습니다. 이 폴더의 이전 ‘Expo 기본 화면’ 설명과 구분하여 최신 앱 상태는 [기능 개발 상태](../FEATURES.md)를 확인하세요. 운영 서비스 참고 원칙은 프로젝트 `AGENTS.md`, 이번 확인 URL과 한계는 `FEATURES.md`에 기록했습니다.

## 광고판 표시와 커뮤니티 탭 (명세 v0.11)

광고판은 기존 공지/추천 배너의 임시 이름이며 실제 광고 연동을 뜻하지 않습니다. 일반 `index.html`은 화면 폭과 무관하게 웹으로 취급해 화살표를 유지합니다. `index.html?mode=app`은 앱 표시 모드로 화살표를 숨깁니다. `app-preview.html`은 PC의 iframe에서도 항상 이 모드를 전달하므로 앱 화면에 화살표가 나타나지 않습니다. 손가락 스와이프는 유지합니다.

광고판 아래 1/n 카운터는 현재 유형의 실제 배너 수와 위치를 표시하며 접근성 설명도 제공합니다. 스와이프·화살표·유형 전환·크기 변경을 반영하고 한 장은 1/1, 빈 목록은 광고판 영역을 숨깁니다. 위치 텍스트만 갱신하므로 화면 전체를 다시 그리거나 독서 기록을 변경하지 않습니다.

하단 순서는 홈·탐색·커뮤니티·마이페이지입니다. 커뮤니티는 공통 헤더와 준비 중 빈 화면뿐이며 게시판·글쓰기·댓글은 추가하지 않았습니다. 기존 서재·독서 기록·찜 데이터와 홈 및 마이페이지의 진입을 보존했습니다. 외부 미리보기 바로가기에는 커뮤니티를 반영하고 서재는 보조 바로가기로 유지합니다.
