# 백과사전 탭 프로토타입

팀원에게 목차 화면에서 백과사전으로 전환하는 흐름을 설명하기 위한 독립형 웹 프로토타입입니다. Expo 앱의 실행 코드와 별도로 동작하며 서버 API를 연결하지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 같은 폴더의 `style.css`와 `app.js`도 함께 유지하세요. 외부 폰트가 로드되지 않아도 시스템 폰트로 동작합니다. 저장소의 Raw 링크는 시연 페이지를 실행하지 않으므로 파일을 내려받아 열거나 로컬 웹 서버로 실행하세요.

## 시연 순서

1. 상단 목차 아이콘 옆 책 버튼을 눌러 백과사전으로 전환합니다.
2. 인물 분류에서 주인공과 조력자 세부 분류를 선택합니다.
3. 세계관 분류를 선택하면 세부 분류 줄이 사라지는 것을 확인합니다.
4. 전체로 돌아와 적합도 등 공개된 항목을 검색합니다.
5. 항목을 눌러 설명을 읽고 목록으로 돌아옵니다. 닫기 버튼, 바깥 영역 또는 Escape로도 닫을 수 있습니다.
6. 데스크톱의 읽기 진도 슬라이더를 3화에서 8화로 움직여 잠긴 항목이 개방되는 것을 확인합니다. 모바일에서는 목차에서 회차를 선택해 시연할 수 있습니다.
7. 목차 버튼을 눌러 회차리스트로 돌아갑니다.

## 콘티 반영

- 기존 상단 메뉴를 유지하고 책 모양 진입 버튼 추가
- 전체 및 분류 탭과 가로 스크롤
- 분류에 세부 탭이 정의되어 있을 때만 해당 줄 표시
- 검색 아래 항목 목록, 항목 선택 시 설명 패널
- 공개 진도에 따른 잠금과 제목·내용 숨김
- 잠긴 항목은 이름과 설명을 검색해도 결과에 노출되지 않음

분류와 세부 분류는 샘플 데이터로 정의되어 있습니다. 편집·추가 기능은 포함하지 않습니다. 작품·인물·설정·통계는 가상 시연 데이터이며 원작의 실제 설정 설명이 아닙니다. 찜과 읽기 위치 등 상태는 새로고침하면 초기화됩니다. 실제 인증·회차 열람·듣기·댓글·저장 API는 이 프로토타입에 연결하지 않았습니다. 파란 표시 위치가 첨부 이미지에서 확인되지 않아 책 버튼을 목차 아이콘 바로 옆에 배치했습니다.
