# 매거진 PNG 콘텐츠 등록

이 연동은 서버 관리자가 준비한 PNG 한 장을 매거진 한 쪽으로 표시합니다. `CONTENT_ROOT`는 애플리케이션의 공개 정적 파일 경로 바깥에 둡니다. 운영 시 서버에서 읽기 전용으로 연결하고 관리자만 원본을 교체합니다.

1. 작품 종류를 매거진으로 지정하고 호 전체 쪽 수를 입력합니다. 기사마다 호 안의 시작 쪽을 설정합니다.
2. 기사 `content_url`에 `/content/magazine/orbit-2026-11/article-2/`처럼 디렉터리를 지정합니다. 경로 구성 요소는 영문·숫자로 시작하며 이후 영문·숫자·밑줄·하이픈을 사용할 수 있습니다. 각 요소는 최대 80자입니다.
3. 해당 디렉터리에 호 기준 `5.png`, `6.png`처럼 파일을 둡니다. 한 파일은 최대 8 MiB, 가로·세로 각각 4096픽셀 및 합계 8,000,000픽셀까지 허용합니다. 심볼릭 링크, Windows 연결 폴더, 손상된 PNG는 읽지 않습니다.
4. 같은 기사의 쪽 원문이나 범위를 바꿀 때 본문 버전을 올리고 디렉터리와 DB 메타데이터를 함께 배포합니다. 이전 버전 요청은 409로 처리됩니다.

예를 들어 첫 기사가 1쪽, 두 번째가 5쪽, 비공개 세 번째 기사가 9쪽에 시작하는 10쪽 호의 공개 범위는 1~4쪽과 5~8쪽입니다. 9~10쪽은 요청할 수 없습니다. 쪽 수를 확정하지 않은 자료는 PNG 뷰어에서 사용할 수 없습니다.

기존 HTML·PDF·외부 주소는 DB에서 유지합니다. 파일 업로드와 PDF 변환, 기존 원본 전환은 [#25](https://github.com/whitetiger0804/Mobtwig/issues/25)에서 다룹니다.
