## 기술 스택

### 백엔드

| 항목 | 선택 | 설명 |
| --- | --- | --- |
| 개발 언어 | Java | 클래스·제네릭·예외 처리에 대한 이해가 필요 |
| 프레임워크 | Spring Boot | (Maven 내장) |
| 데이터 접근 | Spring Data JPA + Hibernate | 자바 객체와 DB데이터 매핑/관리 |
| 의존성 관리·빌드 도구 | Maven | `pom.xml`로 라이브러리 의존성과 컴파일·테스트·패키징 절차 공유 |

### 데이터베이스 (확정)

| 항목 | 선택 | 이유 |
| --- | --- | --- |
| DBMS | MySQL 8.0 | 관계형 데이터(사용자·도서·구매·리뷰 등 PK/FK·연결 테이블)와 트랜잭션 정합성이 필요해 RDBMS로 확정. Java/Spring(JPA·Hibernate) 생태계와 궁합이 좋고, 팀 전체 러닝커브가 낮으며, 무료 호스팅 선택지(AWS RDS 프리티어, Railway 등)가 많음 |
| 마이그레이션 도구 | Flyway | Spring Boot의 표준 마이그레이션 도구로, 스키마 변경 이력을 SQL 파일로 git 관리 가능 |
| 로컬 개발 환경 | Docker Compose | 팀원 전원이 `docker compose up`만으로 동일한 DB 환경을 구성 |
| DB 작업 언어 | Python (SQLAlchemy/PyMySQL) + SQL | 시드/더미 데이터 생성, 스키마 검증 등 DB 담당의 보조 도구로 사용 (실서비스 로직·API는 백엔드 Java/JPA가 담당) |

### 공통 컨벤션
- 컬럼명: `snake_case` (JPA `PhysicalNamingStrategy`가 자바 `camelCase`로 자동 변환)
- 문자셋: `utf8mb4` (이모지·다국어 지원)
- PK: `BIGINT AUTO_INCREMENT`
- FK 컬럼명: `{참조테이블}_id`
- 시간 저장: `TIMESTAMP`, UTC 기준으로 저장 후 클라이언트에서 변환
